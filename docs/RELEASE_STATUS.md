# Package contents

This distribution includes the viewer, local server, saved results, 307 sample reports, 14 exports, four microscopy previews and documentation. It does not include the scientific execution package or dependency binaries.

The viewer is read-only. Selecting samples, changing views and downloading reports never recalculates scientific results.

`PUBLIC_FILES.json` and `CHECKSUMS.sha256` list the included files and hashes. Run `python -B scripts/verify_public_candidate.py .` to verify an extracted copy.
